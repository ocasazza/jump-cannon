# Use Jump Cannon

Jump Cannon turns linked knowledge into an interactive graph. Start in
[[Workspace]], find and change content with [[Nodes Search and Documents]], tune
the view with [[Layouts Metrics and Filters]], and bring in new graph data with
[[Import and Generate]].

The browser and Tauri app are clients of [[Backend API]]. Compute stays behind
that API as described in [[Compute]].
