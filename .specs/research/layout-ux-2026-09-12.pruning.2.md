## Top-3 Vote (ranked)

1. **C2 — Engine capability declarations** (3.88, select) — the only proposal passing all three
   essential gates with a high uncapped score. Data-owned dimensions become unrepresentable *by
   construction* ("inapplicable controls are unrepresentable because they're never constructed"),
   remote engines are first-class (manifests served alongside `/compute/engines`, honest fallback
   form), and behavior derives from existing serde schemas rather than new compiled tables.
2. **C3 — Per-graph-class forms** (3.00, select) — passes all three essential gates and explicitly
   names Remote and Static forms. The Molecular form is the most concretely honest molecule UX in the
   set (UFF summary as provenance, one geometry-scale multiplier, no cooling/halt/backend). Held back
   by the CK-010 pitfall (−0.25: bespoke per-class forms) and weak generality — a seventh graph class
   demands a new bespoke form.
3. **C1 — Regime-as-data registry** (2.00 after essential gate; wins rank 3 on tie-breaks: D1=4,
   D2=4, zero pitfall YESes) — the strongest capped proposal: dead knobs "absent by construction",
   presets migrate from hardcoded Rust to data (honors "packages, not crates"), auto-resolution is
   legible ("the capsule always says *why*"). Its gate failure is narrow and fixable in full
   development: remote engines and static solvers are never named, though the registry mechanism
   (engine + option values + applicability predicates) already subsumes both. Per the spec's
   essential gate its `overall_label` cannot exceed **hold**; I flag the conflict with the
   selection_goal (top 3 for development) and vote for it as rank 3 with that caveat explicit.

## Method and verification notes

- Reference model (built before scoring): a layered provenance model (data-owned / regime / user)
  where data-owned dimensions never render as live knobs anywhere (including advanced/escape-hatch
  surfaces); one mechanism covering all six named use cases incl. remote engines and static solvers;
  derivation from existing signals (TYPED_FORCE_SUMMARY, for_n_nodes, settings JSON); migration or
  preservation of jc_layout_v1 / `?config=` / preset detection; vault presets never offered to typed
  graphs.
- Codebase claims verified: `TYPED_FORCE_SUMMARY` (app/ui/src/graph_canvas.rs:206; consumed by the
  lying banner at panels/layout.rs:3606-3609), `jc_layout_v1` (panels/layout.rs:53), `LayoutPreset`
  Fast/Balanced/Pretty with spring_len 40/60/80 and `LayoutPreset::detect` (panels/layout.rs:1079-1130,
  3584), `for_n_nodes` (layout.rs:119-129), Timeline panel with position ring + scrub + pause
  (panels/timeline.rs — confirms B5's premise already exists), cursor forces
  `cursor_pos/radius/strength` (render/pipelines.rs:1544-1549 — confirms B2's premise), Monaco TOML
  surface (panels/importers.rs:1540 — confirms C6's premise), remote engine bridges
  (layout.rs:55-56). No high score below rests on an unverifiable claim; C2's "manifests served
  alongside `/compute/engines`" is a proposed addition, not a claim about today, and is scored as such.
- Essential gate (spec): CK-001/CK-002/CK-003 any NO → final score capped at 2.0, label ≤ hold.
  Pitfalls CK-010/011/012 YES → −0.25 each (floor 1.0). Tie-breaks: D1 score, D2 score, fewer
  pitfall YESes; residual ties noted and split by pre-cap adjusted score (spec's tie-breakers
  exhausted).
- Consistency rulings applied uniformly: (a) CK-001 requires all six cases addressed in text —
  an explicitly universal mechanism plus explicit treatment of the hard cases (remote, static);
  (b) CK-002 fails wherever the raw flat constants survive as live controls (advanced drawers,
  tune/escape-hatch surfaces) without a stated collapse/disable — A2 passes only because its
  Advanced explicitly carries "provenance chips and dead-knob collapse"; (c) CK-012 is YES where a
  user-facing list offers Fast/Balanced/Pretty with no stated class filtering (A1, A2, A3), NO where
  applicability predicates or per-regime paths keep them off typed graphs or where the proposal
  gives no positive evidence they remain.
